# 90-Day Cybersecurity Roadmap

## 1. Objective

To develop practical cybersecurity skills and become competitive for entry-level cybersecurity roles in the UK.

This roadmap focuses on three areas:

- Security Operations Centre (SOC)
- Governance, Risk and Compliance (GRC)
- General Cybersecurity Analysis

## 2. Duration

12 November 2026 – 9 February 2027.

## 3. Learning Approach

The roadmap combines:

- Structured online learning through Alison.
- Independent practical cybersecurity laboratories.
- Linux and networking exercises.
- SOC monitoring and incident investigation.
- GRC frameworks and risk assessments.
- Practical documentation and GitHub portfolio development.

## 4. Weekly Learning Plan

| Week | Focus |
|---|---|
| 1 | Networking and Linux fundamentals |
| 2 | Network security and traffic analysis |
| 3 | SOC fundamentals and security monitoring |
| 4 | GRC and risk management |
| 5 | SIEM and security investigations |
| 6 | Incident response |
| 7 | Identity and Access Management |
| 8 | Vulnerability assessment |
| 9 | ISO 27001 and NIST frameworks |
| 10 | Practical cybersecurity projects |
| 11 | Technical interview preparation |
| 12 | CV, LinkedIn and job applications |

## 5. Tools and Platforms

- Kali Linux
- Virtual Machine
- Wireshark
- Nmap
- Wazuh
- Microsoft Sentinel
- Alison learning platform

## 6. Practical Evidence

Completed exercises will be documented using:

- Screenshots
- Commands and configurations
- Investigation notes
- Lab reports
- Findings and recommendations

## 7. Progress Tracking

Each activity will be identified as:

- Planned
- In Progress
- Completed

Only completed work will be presented as completed.

## 8. Expected Outcomes

By the end of the roadmap, the objectives are to have:

- Improved practical cybersecurity skills.
- Completed SOC, GRC and technical security exercises.
- Developed a documented cybersecurity portfolio.
- Improved interview readiness.
- Established a consistent UK cybersecurity job application strategy.
